# 꼭 해야 할 일 (TodoList)

> 하루의 할 일을 빠르게 추가하고, 완료하고, 정리할 수 있는 완성도 높은 개인용 한국어 TodoList 웹 애플리케이션입니다.

---

## 1. 주요 기능

- **할 일 추가**:
  - `Enter` 키 또는 `추가` 버튼으로 신속한 등록
  - 앞뒤 공백 자동 제거, 빈 입력 및 공백만 있는 입력 차단 (`aria-describedby` 에러 메시지 연결)
  - 최대 200자 글자 수 제한 및 카운터 지원
  - 한글 IME(자모 결합) 조합 중 `Enter` 시 의도치 않게 등록되지 않도록 방지 (`isComposing` 제어)
  - 등록 후 입력창 초기화 및 포커스 유지
  - 최신 항목이 항상 목록 맨 위에 정렬
  - 현재 필터/검색 조건에 의해 숨겨진 경우 숨김 안내 배너 및 `전체 보기` 원클릭 복귀 제공

- **완료 상태 관리**:
  - 네이티브 체크박스 및 할 일 텍스트 클릭으로 완료/미완료 토글
  - 완료 항목에 명확한 취소선 및 저대비(`text-muted`) 스타일 적용 (액션 버튼은 정상 가시성 유지)

- **내용 수정**:
  - `수정` 버튼 클릭 시 인라인 편집 모드 전환 및 입력창 자동 포커스
  - `저장` 버튼 또는 `Enter`로 수정 저장, `Esc` 또는 `취소` 버튼으로 원래 내용 복원
  - 빈 내용 저장 차단 및 유효성 검사 경고
  - 저장/취소 후 수정 버튼으로 키보드 포커스 안전 복귀
  - 수정 시 생성일(`createdAt`)과 완료 상태(`completed`)는 불변 유지 (`updatedAt`만 갱신)

- **개별 삭제 및 실행 취소 (Undo Toast)**:
  - 개별 항목 삭제 시 화면 하단에 비침습적 실행 취소 토스트 알림 노출 (`role="status"`, `aria-live="polite"`)
  - `실행 취소` 클릭 시 원래 데이터(`id`, 내용, 완료 상태, 생성일)와 원래 정렬 순서 복원
  - 연속 삭제 시 가장 최근에 삭제된 항목 1건이 실행 취소 대상이 됨
  - 삭제 후 키보드 포커스가 목록의 인접 요소 또는 입력창으로 자연스럽게 이동

- **필터 및 검색**:
  - 상태 필터: `전체`, `진행 중`, `완료` (`aria-pressed` 기반 실제 버튼)
  - 실시간 검색: 대소문자 무시 부분 일치 검색 및 상태 필터와의 교집합 적용
  - 검색어 초기화(`×`) 버튼 제공 및 포커스 복귀
  - 검색 결과 개수 및 필터별 건수 안내
  - "전체 할 일 없음", "진행 중 없음", "완료 없음", "검색 결과 없음" 등 상황별 빈 상태(Empty State) 분기 및 복귀 동작 제공

- **완료 항목 일괄 삭제 (Modal Dialog)**:
  - 완료된 항목이 없으면 비활성화
  - 클릭 시 삭제 대상 개수(`N개`)를 안내하는 확인 대화상자 노출
  - `<dialog>` 기반 포커스 트랩, `Esc` 취소, 배경(Backdrop) 클릭 취소, 대화상자 닫힘 후 호출 버튼으로 포커스 복귀

- **통계 및 진행률**:
  - 한국어 로컬 날짜 자동 표시 (예: `2026년 11월 26일 목요일`)
  - 전체 수, 완료 수, 남은 할 일 수 실시간 집계
  - 완료율(%) 계산 및 접근 가능한 진행률 막대(`role="progressbar"`)
  - 할 일이 0개일 때 `0으로 나누기` 오류를 방지하여 `0%` 표시

- **안전한 자동 저장 (Local Storage)**:
  - `localStorage`에 자동 저장 및 브라우저 새로고침 시 복원
  - 스키마 버전 관리 (`schemaVersion: 1`, `STORAGE_KEY: "todo-app:v1"`)
  - JSON 파싱 오류, 데이터 필드 결손, 중복 ID, 유효하지 않은 날짜 검증
  - 손상된 데이터 발생 시 기존 데이터를 덮어쓰지 않고 원본 보존 안내 및 클립보드 복사, 사용자 확인 후 초기화 기능 제공
  - 브라우저 스토리지 할당량 초과 시 메모리 상태를 유지하고 사용자에게 명확한 오류 안내 및 재시도 기능 제공

## 2. 저장 방식 및 제한사항

- **저장 범위**: 본 애플리케이션의 데이터는 **사용자의 현재 웹 브라우저 로컬 저장소(`localStorage`)**에만 저장됩니다.
- **클라우드 동기화 없음**: 별도의 백엔드 데이터베이스, 로그인 계정 시스템, 유료 클라우드 백업 서비스가 연동되어 있지 않으므로 브라우저 캐시 삭제 시 데이터가 제거될 수 있습니다.
- **다중 탭 충돌**: 현재 버전은 단일 탭 사용을 기본으로 설계되었으며, 여러 탭 간의 실시간 충돌 조정은 포함되지 않습니다.
- **실행 취소 범위**: 연속 삭제 시 시스템 혼선을 방지하기 위해 **가장 최근에 삭제된 1건**만 실행 취소 대상이 됩니다.

## 3. 기술 스택 및 디자인 시스템

- **프레임워크 / 빌드**: React 18, TypeScript, Vite 6
- **스타일링**: CSS Custom Properties 기반 디자인 토큰 (`DESIGN.md` 단일 원천 준수)
- **테스트**: Vitest, React Testing Library, User Event, JSDOM
- **접근성(a11y)**: WCAG 2.1 AA 기준 준수 (대비 최소 4.5:1, 터치 타겟 최소 44px 이상, 키보드 완전 탐색, WAI-ARIA 명세 준수)

## 5. 실행 및 빌드 명령

### 1) 의존성 설치
```bash
npm install
```

### 2) 로컬 개발 서버 실행
```bash
npm run dev
```
기본적으로 `http://localhost:5173`에서 실행됩니다.

### 3) 단위 및 통합 테스트 실행
```bash
npm run test
```
Vitest를 통해 총 24개의 자동화 테스트(스토리지 검증, UI 인터랙션, 접근성, 에지 케이스)를 수행합니다.

### 4) 프로덕션 빌드
```bash
npm run build
```
TypeScript 컴파일(`tsc`) 및 Vite 번들링을 수행하여 최적화된 정적 에셋(`dist/`)을 생성합니다.

### 5) 프로덕션 미리보기
```bash
npm run preview
```
